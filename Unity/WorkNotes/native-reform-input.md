# Reform için gerçek Windows girdi yöntemi

`tools/native-reform.script` üç75 saniyelik pencere içerir. Root mevcut sahiplik/provenance guard'larıyla `-PlayerTimeoutSeconds 300` vermelidir. Bu ajan hiçbir süreç başlatmadı. Script yeni kampanya/normal panel ve bölge seçimi dışında reform işlemi göndermez: `reform draft`, `reform begin` veya `reform end` yoktur. Gerçek girişimler daha sonra ayrı receipt ile değerlendirilir; henüz native PASS sonucu yoktur.

1. `00-start` 12 saniyelik readiness süresi içinde gelir: Normandy, RU, reform belgesi, henüz proje yok. İlk75 saniyede root gerçek **commerce**, sonra **provisioning** düğmesine tıklar ve iki ara PNG'yi görür. İncelenen first build1440×900 karesinde merkezler yaklaşık commerce1340,329 / provisioning1218,329. Bunlar gerçek kareden okunan başlangıç koordinatlarıdır; aday metin yerleşimi değişirse yeni kare esas alınır. `01-native-drafts-only` bütün campaign'in00 ile aynı olduğunu doğrular. Tek başına son JSON iki UI geçişini ispatlamaz; ara input PNG'leri gereklidir.
2. Yeni01 checkpoint'ten sonraki75 saniyede root document altında gerçek Begin'e **bir kez** basar. Wheel−10 yalnız document içindeyken; gerekiyorsa yeni kareyle ilerlenir. İncelenen provisioning alt karesinde Begin yaklaşık1280,740'tadır. `02-native-paid-pending`: Week0, Gold720, Power51, Food360, supplies120, Troops1200, Manpower2400, Normandy provisioning4 adım; Morel ilişkisinin hâlâ50 olduğu JSON'dan ayrıca incelenmelidir. Bu pencere `week` yapmaz.
3. Script sıradan `select brittany` yapar, reform belgesini üstten açar ve `03-original-region-after-selection` kaydını verir. Root burada farklı seçili bölgeye rağmen belgenin Normandy projesini gösterdiğini görür. Son75 saniyede document altında gerçek End'e basar. Düğme yeri henüz bu pending karesinden ölçülmemiştir; Begin'in eski y koordinatı otomatik olarak kullanılamaz. `04-native-original-project-ended` aynı Gold720 / Power51 / Food360 ve bütün asker/rezerv/supplies değerlerini, kapalı projeyi ve hâlâ Week0'ı doğrular. JSON'da yalnız Morel50→42, reform alanları ve tek end journal kaydı beklenir; Valcourt50 kalır. `05-ended-loaded` gerçek save/load sonrası aynı olmalıdır.

Snapshot/capture adları00–05 aynı; altı JSON ve altı PNG beklenir. Script iki belge sonu kaydırmasını gerçek girdiye bırakır; ilk setup veya üçüncü pencere başındaki readonly panel/scroll, Begin/End tıklaması yerine geçmez.
