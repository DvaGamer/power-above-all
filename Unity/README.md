# Unity çalışma kopyası

Bu klasör Unity aktarımının devam eden kaynaklarını içerir. Bu ara kayıt henüz açılabilir veya doğrulanmış bir Unity sürümü değildir; başlatma sahnesi ve modül entegrasyonu hazırlanmaktadır.

Hedef editör: Unity 6000.3.23f1 LTS. Oyun dilleri: Rusça ve Türkçe.

Geçerli aşama: **0.2 Visual & Feel Polish Pass**. Yeni mekanik eklenmez. Mevcut döngünün sunumu ve kullanım hissi iyileştirilir. Çalışan tarayıcı 0.1 kök dizindeki `START.cmd` ile açılabilir.

Çekirdek C# bağımsız derleyicide kontrol edildi. Unity içindeki testler, sahne ve görsel doğrulama henüz tamamlanmadı.
